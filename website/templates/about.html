About The Vault

Private, Isolated Storage for Your Data

The Vault is a personal cloud storage and note-taking application designed to provide full ownership and security for your files.

How Security & Storage Work:
  • Password Hashing (Werkzeug): Your password is never saved directly. It is processed through a cryptographic one-way hashing function with a unique salt. Even if someone inspects the database, they cannot reverse the stored string back into your actual password.
  • Database BLOB Storage: Uploaded files are converted directly into raw bytes (Binary Large Objects / BYTEA in PostgreSQL) and saved inside protected database rows rather than being left exposed in public web server directories.
  • In-Memory File Serving: When downloading, files are assembled dynamically in application memory (BytesIO) and piped directly to your connection. No public links or static URLs are ever generated.
  • Strict User Isolation: Every query enforces tenant boundaries, ensuring users only ever have access to their own files and notes.
