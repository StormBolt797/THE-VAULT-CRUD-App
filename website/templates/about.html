About The Vault

Next-Generation Document Security

The Vault is a personal cloud storage platform engineered to provide a private, sovereign repository for your digital assets, notes, and records.

How Security & Storage Work:
  • Cryptographic Password Hashing: User passwords are never saved in plaintext. Credentials are salted and hashed using modern cryptographic algorithms (scrypt via Werkzeug), protecting your master access even against database dumps.
  • Database-Level Binary BLOB Encapsulation: Unlike standard web drives that expose files in publicly addressable static web folders, The Vault digests your files into raw byte streams (BYTEA / BLOBs) stored in isolated PostgreSQL records.
  • Zero Public Links / Memory Streaming: No persistent static links are ever generated for uploaded files. Downloads are reconstituted on-the-fly inside volatile application memory (io.BytesIO) and streamed directly to your browser session.
  • Session-Scoped Isolation: Every record is linked strictly to your authenticated session ID. Cross-tenant leakage is prevented through server-level query filtering.
